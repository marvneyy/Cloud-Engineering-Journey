## 📚 Learning Method

My learning process focuses on:

1. **Learn** — Study the scheduled topic and learning resources.
2. **Understand** — Write simple notes and clarify concepts.
3. **Practise** — Complete hands-on labs using available tools.
4. **Document** — Record commands, results, and lessons learned.
5. **Review** — Revise previous topics and strengthen understanding.
6. **Build** — Develop projects to demonstrate practical skills.

I focus on understanding concepts, practising safely, and documenting what I actually complete.
