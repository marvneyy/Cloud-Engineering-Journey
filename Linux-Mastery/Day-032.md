## 💻 Commands Used — Users and Permissions

#### 1. Check the Current User

```bash
whoami
```

**Use:** Displays the username of the current account.

#### 2. Check Sudo Permissions

```bash
sudo -l
```

**Use:** Shows which administrative commands the current user is allowed to run.

#### 3. Create a New User

```bash
sudo useradd -m deployer
```

**Use:** Creates a user named `deployer` and creates its home directory.

#### 4. Switch to Another User

```bash
su - deployer
```

**Use:** Opens a login shell as the `deployer` user.

#### 5. Return to the Previous Shell

```bash
exit
```

**Use:** Exits the current shell and returns to the previous one.

#### 6. Add a User to the Sudo Group

```bash
sudo usermod -aG sudo deployer
```

**Use:** Adds `deployer` to the `sudo` group without removing existing group memberships.

#### 7. Check Group Membership

```bash
groups deployer
```

**Use:** Displays the groups that the `deployer` user belongs to.

#### 8. Test Administrative Access

```bash
sudo whoami
```

**Use:** Displays `root` if the command successfully runs with root privileges.

## 📂 Additional Linux Commands

#### 9. Find Files

```bash
find . -name "file.txt"
```

**Use:** Searches for `file.txt` inside the current directory and its subdirectories.

#### 10. Move or Rename a File

```bash
mv file.txt src/file1.txt
```

**Use:** Moves `file.txt` into the `src` directory and names it `file1.txt`.

**Note:** The `src` directory must already exist.

#### 11. Display the First Line

```bash
head -n 1 file.txt
```

**Use:** Displays the first line of `file.txt`.

#### 12. Write Text into a File

```bash
echo "hi" > file2.txt
```

**Use:** Writes `hi` into `file2.txt`. If the file already contains content, `>` overwrites it.

#### 13. Display Multiple Files

```bash
cat file2.txt file3.txt
```

**Use:** Displays the contents of both files in the terminal, one after the other.

#### 14. Create or Overwrite a File Using `cat`

```bash
cat > file.txt
```

**Use:** Accepts text from the keyboard and writes it into `file.txt`.

Type:

```text
hi i am marvan
```

Then press **Ctrl + D** to finish input and save the entered text.

**Important:** This command overwrites existing content in `file.txt`.

### 15. Save in the Nano Editor

**Keyboard shortcut:**

```text
Ctrl + O
```

**Use:** Saves the current file in the Nano text editor. Press **Enter** to confirm the filename.

## 🧠 Important Concepts

### What Is the Root User?

The `root` user is the Linux superuser with extensive administrative privileges.

### What Is Sudo?

`sudo` allows an authorized user to run a command with elevated privileges without logging in directly as root.

### Why Is Sudo Safer?

- Users can work using their own accounts.
- Administrative access can be controlled through permissions.
- Sudo activity can be logged for auditing.
- Sharing the root password across a team is avoided.

---

## 🔐 Security Reminder

Use administrator privileges only when necessary. Be especially careful with commands that overwrite files or modify user accounts.
