## 1. What is Bash Scripting?

Bash scripting means writing multiple Linux commands inside a single file and executing them together.

Instead of manually typing every command, we can create a `.sh` file and run it.

**Example:** `setup.sh`

## 2. Understanding the Script

```bash
#!/bin/bash

# Initial Server Setup Script

apt update

mkdir -p /var/www/myapp

useradd -m webadmin

echo "Server Setup Complete"
```

### Explanation of Each Line

**1. `#!/bin/bash`**

- Known as the shebang.
- Tells Linux to use the Bash interpreter to execute the script.

**2. `# Initial Server Setup Script`**

- This is a comment.
- Explains the purpose of the script.
- Comments are not executed by Bash.

**3. `apt update`**

- Refreshes the Ubuntu package information.
- Does not upgrade installed packages.

**4. `mkdir -p /var/www/myapp`**

- `mkdir` creates a directory.
- `-p` creates missing parent directories and avoids an error if the directory already exists.
- `/var/www/myapp` is the application directory.

**5. `useradd -m webadmin`**

- Creates a new Linux user named `webadmin`.
- `-m` creates a home directory for that user.
- Home directory: `/home/webadmin`

**6. `echo "Server Setup Complete"`**

- Displays a message in the terminal.
- Output: `Server Setup Complete`

## 3. Important Commands

| Command | Purpose |
|---|---|
| `nano setup.sh` | Create or edit a script |
| `chmod +x setup.sh` | Give the file execute permission |
| `sudo ./setup.sh` | Run the script directly with administrator privileges |
| `sudo bash ./setup.sh` | Run the script using Bash with administrator privileges |
| `cat setup.sh` | Display script contents |
| `ls -l setup.sh` | Check file permissions |
| `file setup.sh` | Identify file type |

**Note:** I used `sudo bash ./setup.sh` to execute my script successfully.

## 4. Practical Lab – Creating a Bash Script

### Step 1: Create the script

```bash
nano setup.sh
```

### Step 2: Add the script commands

```bash
#!/bin/bash

# Initial Server Setup Script

apt update
mkdir -p /var/www/myapp
useradd -m webadmin

echo "Server Setup Complete"
```

Save and exit Nano:

- `Ctrl + O` → Save
- `Enter` → Confirm filename
- `Ctrl + X` → Exit

### Step 3: Give execute permission

```bash
chmod +x setup.sh
```

### Step 4: Execute the script

```bash
sudo bash ./setup.sh
```

### Step 5: Verify the results

Check the Linux user:

```bash
id webadmin
```

Check the application directory:

```bash
ls -ld /var/www/myapp
```

## 5. Real-World Applications

Bash scripting is useful in Cloud Engineering and Linux Administration.

Examples:

- Automating server setup.
- Creating directories and users.
- Updating package information.
- Automating repetitive Linux commands.
- Reducing manual work.

## 6. Important Lessons Learned

- A Bash script is a file containing Linux commands.
- The `.sh` extension is commonly used for shell scripts.
- The shebang identifies the interpreter.
- `chmod +x` gives execute permission.
- `sudo` provides administrator privileges when required.
- A script can execute multiple commands in sequence.

**Important:** Running a script again may produce errors if a resource, such as a Linux user, already exists.
