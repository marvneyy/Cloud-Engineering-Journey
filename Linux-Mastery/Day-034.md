# 📅Day 34 – Linux Process Management & Monitoring

## 🎯 Goal
Learn how to identify running processes, find their PIDs, stop unwanted or unresponsive processes, and monitor server performance using CPU, RAM and Load Average.

---

### 1. What is a Process?

A process is a program or application that is currently running on a computer.

**Examples:** Firefox, Chrome, Database services.

**Purpose:** Helps us understand and manage applications running on a Linux server.

### 2. What is PID?

PID (Process ID) is a unique identification number assigned to each running process.

**Example:**
```text
PID     PROCESS
4737    firefox
6293    sleep
```

**Purpose:** Helps us identify and manage a specific process without confusing it with other running applications.

### 3. Important Linux Commands

| Command | Purpose |
|---|---|
| `ps` | Shows processes associated with the current terminal. Useful for checking commands running in your session. |
| `ps aux` | Displays detailed information about running processes, including their user, PID, CPU and memory usage. |
| `ps -ef` | Displays a detailed list of processes, including their parent process ID (PPID). Useful for checking process relationships. |
| `grep` | Searches text for a specific word or pattern. Useful for finding a particular process in command output. |
| `sleep 1000 &` | Starts a process that waits for 1000 seconds in the background. Useful for practising process management. |
| `kill PID` | Sends a normal termination signal (SIGTERM) to a process, requesting it to stop gracefully. |
| `kill -9 PID` | Sends SIGKILL to forcefully terminate a process when normal termination is insufficient. |
| `top` | Displays live system information, including CPU usage, RAM usage and running processes. |
| `htop` | Provides an interactive, easy-to-read view of processes and system resource usage. |

### 4. Background Process

```bash
sleep 1000 &
```

**Explanation:**
- `sleep` – Makes the process wait for a specified time.
- `1000` – Waits for 1000 seconds.
- `&` – Runs the process in the background.

**Purpose:** Allows a process to run without keeping the terminal busy. We use this command to practise finding and stopping background processes.

### 5. Find a Process

```bash
ps -ef | grep sleep
```

**Explanation:**
- `ps -ef` – Displays the process list.
- `|` – Sends the output of one command to another command.
- `grep sleep` – Searches for lines containing the word `sleep`.

**Purpose:** Helps us find a particular process and identify its PID.

**Note:** The output may also show the `grep` command itself. Do not confuse it with the actual process.

### 6. Kill a Process

#### Normal Termination
```bash
kill PID
```

**Purpose:** Requests the process to stop normally, allowing it to perform cleanup before exiting.

#### Force Termination
```bash
kill -9 PID
```

**Purpose:** Forcefully stops a process that does not respond to a normal termination request.

**Important:** Replace `PID` with the actual process ID. Always verify the PID before terminating a process. Avoid using `kill -9` unless necessary.

### 7. Server Monitoring

#### top
```bash
top
```

**Purpose:** Monitors the server in real time. Helps identify processes consuming CPU and memory resources.

#### htop
```bash
htop
```

**Purpose:** Provides an interactive dashboard to view running processes, CPU usage and memory usage more easily.

Press `q` to exit.

#### Important Monitoring Metrics

- **CPU:** Shows how much processing power is being used by running tasks.
- **RAM:** Shows how much system memory is being used.
- **Load Average:** Shows the average system workload over the last 1, 5 and 15 minutes.

**Why is monitoring important?**

It helps identify high resource usage, slow performance and processes that may need investigation.

### 8. Important Takeaways

- Process = A running program or application.
- PID = Unique identification number of a process.
- `ps` = View processes.
- `grep` = Search for a process.
- `kill` = Request process termination.
- `kill -9` = Forcefully terminate a process.
- `top` / `htop` = Monitor system performance.
- CPU and RAM = Important server resources.
