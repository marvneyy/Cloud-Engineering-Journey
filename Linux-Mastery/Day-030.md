# 📅Day 30 — Linux File Management

## 🎯 Goal
Learn how to create folders, create files, copy files, rename files, and delete folders using Linux commands.

## 📚 Topics Covered
- Directory creation
- File creation
- Copying files
- Renaming files
- Deleting directories

## 💻 Commands Learned

| Command | Purpose |
|---|---|
| `mkdir -p` | Creates nested directories |
| `touch` | Creates an empty file |
| `cp` | Copies a file |
| `mv` | Moves or renames a file |
| `rm -r` | Deletes a directory and its contents |
| `ls` | Lists files and directories |
| `ls -R` | Lists directory contents recursively |

## 🧪 Hands-On Lab

### Step 1: Create nested directories

```bash
cd ~
mkdir -p project/src/files
```

**Purpose:** Creates the `project/src/files` directory structure inside the home directory.

### Step 2: Create an empty file

```bash
touch project/src/files/hello.txt
```

**Purpose:** Creates an empty file named `hello.txt` inside the `files` directory.

### Step 3: Copy the file

```bash
cp project/src/files/hello.txt project/src/
```

**Purpose:** Copies `hello.txt` into the `src` directory. The original file remains in `files`.

### Step 4: Rename the copied file

```bash
mv project/src/hello.txt project/src/hello-renamed.txt
```

**Purpose:** Renames the copied file to `hello-renamed.txt`.

### Step 5: Delete the `files` directory

```bash
rm -r project/src/files
```

**Purpose:** Deletes the `files` directory and its contents.

### Step 6: Verify the result

```bash
ls -R project
```

Expected structure:

```text
project/
└── src/
    └── hello-renamed.txt
```

## 🧠 Key Learnings

- `mkdir -p` creates nested directories.
- `touch` creates an empty file.
- `cp` copies a file while keeping the original.
- `mv` moves or renames a file.
- `rm -r` deletes a directory and its contents.
- `ls -R` helps verify directory structures.

## ⚠️ Safety Note

Be careful when using `rm -r` or `rm -rf`. Deleted files may be difficult or impossible to recover. Always verify the path before deleting anything.
