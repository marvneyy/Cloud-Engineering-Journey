## 🧪 Day 18 Hands-On Lab — Browser Developer Tools

### Objective
To inspect HTTP/HTTPS requests using the browser's Developer Tools Network tab.

### Tool Used
- Google Chrome Developer Tools

### Steps Performed

1. Opened Google Chrome.
2. Opened Developer Tools using `F12`.
3. Navigated to the **Network** tab.
4. Opened Google.
5. Selected a network request from the request list.
6. Inspected the request details and response headers.

### Observations

#### Request URL
The selected request used HTTPS:

`https://www.gstatic.com/...`

This shows that the request was made using HTTPS.

#### Request Method
`GET`

The browser used a GET request to retrieve the resource.

#### Status Code
`200 OK (from disk cache)`

The request was successful.

The "from disk cache" message indicates that Chrome served the resource from its local cache.

#### Response Headers
Inspected response headers including:

- `Access-Control-Allow-Origin`
- `Age`
- `Alt-Svc`

### Result

Successfully used Chrome Developer Tools to inspect a real network request and identify:

- Request URL
- Request Method
- Status Code
- Response Headers
- HTTPS request
