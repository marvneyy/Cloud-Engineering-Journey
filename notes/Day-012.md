1. Usable host formula (2𝑛−22n−2)

Usable Host Formula
Usable Hosts = 2ⁿ − 2

n = number of Host Bits

Why −2?

1 → Network Address ❌
1 → Broadcast Address ❌

So:

Usable Hosts = Total IPs − 2

Example: /26
IPv4 = 32 bits

32 − 26 = 6 Host Bits

Then:

2⁶ − 2
= 64 − 2
= 62

So:

/26 = 62 usable hosts
🧠 Easy way to remember

First find Host Bits → 32 − CIDR

Then → 2ⁿ − 2

/24 → 32−24 = 8 → 2⁸−2 = 254 hosts
/25 → 32−25 = 7 → 2⁷−2 = 126 hosts
/26 → 32−26 = 6 → 2⁶−2 = 62 hosts

One-line notebook note:

Usable Hosts = 2ⁿ − 2, where n is the number of Host Bits.

192.168.10.62

192.168.10.0   → Network ID ❌

     ...

2. Default Gateway Selection

First, remember:

Default Gateway = the device that helps your device reach another network.

Usually, the router's IP address is used as the default gateway.

Example

Your network:
---
192.168.1.0/24
---
Router:
---
192.168.1.1
---
Laptop:
---
192.168.1.10
---
Phone:
---
192.168.1.20
---
So:
---
Laptop Default Gateway = 192.168.1.1
Phone Default Gateway  = 192.168.1.1
---
Why?

Because 192.168.1.1 is the router that can send traffic outside the local network.
---
Laptop
192.168.1.10
      ↓
192.168.1.1
Router / Gateway
---      ↓
Internet 🌐
🧠 Easy rule

Default Gateway should be an IP address of the router inside the same subnet as the device.

For example:
---
Device:  192.168.1.50/24
Gateway: 192.168.1.1   ✅

Device:  192.168.1.50/24
Gateway: 192.168.2.1   ❌
---
Because 192.168.2.1 is in a different subnet.

3. Reserving IPs for Router Interfaces

A router interface is the router's connection to a network.

That interface needs an IP address.

Example:

Network: 192.168.10.0/24

We can give the router interface:

Router interface = 192.168.10.1

Then:

Router
192.168.10.1
     │
     ├── PC    192.168.10.10
     ├── Phone 192.168.10.20
     └── VM    192.168.10.30

All these devices can use:

Default Gateway = 192.168.10.1
Why reserve an IP for the router?

Because devices need to know:

"Which IP should I send traffic to when the destination is outside my network?"

That IP is the router's interface IP.

🚨 Important

Don't assign these to the router:

192.168.10.0   ❌ Network ID
192.168.10.255 ❌ Broadcast

Use a usable host address:

192.168.10.1   ✅ Router
🧠 Real example

Suppose:

Network = 192.168.10.0/26

Then:

Network ID  = 192.168.10.0
Usable      = 192.168.10.1 → 192.168.10.62
Broadcast   = 192.168.10.63

We can choose:

Router = 192.168.10.1

Then:

Router Interface
192.168.10.1
       ↓
Default Gateway
       ↓
PCs / Phones / VMs
192.168.10.2 - 192.168.10.62
🔥 Remember this

Default Gateway → the router's IP used to reach other networks.

Router Interface IP → an IP assigned to the router on that particular network.

Same subnet → the device and gateway must be in the same network.
