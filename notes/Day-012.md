📅 **Day 12 – Usable Host Formula, Default Gateway Selection & Reserving IPs for Router Interfaces**

**Topics**

• Usable host formula (2ⁿ − 2)
• Default gateway selection
• Reserving IPs for router interfaces

---

**1. Usable Host Formula (2ⁿ − 2)**

**Usable Host Formula**

```text
Usable Hosts = 2ⁿ − 2
```

**n = number of Host Bits**

**Why −2?**

```text
1 → Network Address ❌
1 → Broadcast Address ❌
```

So:

```text
Usable Hosts = Total IPs − 2
```

**Example: /26**

```text
IPv4 = 32 bits

32 − 26 = 6 Host Bits
```

Then:

```text
2⁶ − 2
= 64 − 2
= 62
```

So:

```text
/26 = 62 usable hosts
```

**🧠 Easy Way to Remember**

First find Host Bits:

```text
32 − CIDR
```

Then:

```text
2ⁿ − 2
```

Examples:

```text
/24 → 32 − 24 = 8 → 2⁸ − 2 = 254 hosts

/25 → 32 − 25 = 7 → 2⁷ − 2 = 126 hosts

/26 → 32 − 26 = 6 → 2⁶ − 2 = 62 hosts
```

**One-Line Notebook Note**

> Usable Hosts = 2ⁿ − 2, where n is the number of Host Bits.

---

**62 Usable Host IPs**

```text
192.168.10.0   → Network ID ❌
192.168.10.1   → Host ✅
...
192.168.10.62  → Host ✅
192.168.10.63  → Broadcast ❌
```

**🧠 Remember**

```text
Network ID = First Address
Host       = Middle Addresses
Broadcast  = Last Address
```

**2. Default Gateway Selection**

First, remember:

> **Default Gateway = the device that helps your device reach another network.**

Usually, the router's IP address is used as the default gateway.

**Example**

**Your Network:**

```text
192.168.1.0/24
```

**Router:**

```text
192.168.1.1
```

**Laptop:**

```text
192.168.1.10
```

**Phone:**

```text
192.168.1.20
```

**So:**

```text
Default Gateway = 192.168.1.1
```

Because `192.168.1.1` is the router that can send traffic outside the local network.

```text
Laptop
192.168.1.10
     ↓
192.168.1.1
Router / Gateway
     ↓
Internet 🌐
```

**🧠 Easy Rule**

> Default Gateway should be an IP address of the router inside the same subnet as the device.

**For Example:**

```text
Device:  192.168.1.50/24
Gateway: 192.168.1.1   ✅
```

Because:

```text
192.168.2.1
```

is in a different subnet.

**3. Reserving IPs for Router Interfaces**

A router interface is the router's connection to a network.

That interface needs an IP address.

**Example**

```text
Network: 192.168.10.0/24
```

We can give the router interface:

```text
Router interface = 192.168.10.1
```

Then:

```text
Router
192.168.10.1
│
├── PC     192.168.10.10
├── Phone  192.168.10.20
└── VM     192.168.10.30
```

All these devices can use:

```text
Default Gateway = 192.168.10.1
```

**Why reserve an IP for the router?**

Because devices need to know:

> "Which IP should I send traffic to when the destination is outside my network?"

That IP is the router's interface IP.

---

**🚨 Important**

Don't assign these to the router:

```text
192.168.10.0   ❌ Network ID
192.168.10.255 ❌ Broadcast
```

Use a usable host address:

```text
192.168.10.1   ✅ Router
```

---

**🧠 Real Example**

Suppose:

```text
Network = 192.168.10.0/26
```

Then:

```text
Network ID = 192.168.10.0

Usable     = 192.168.10.1 → 192.168.10.62

Broadcast  = 192.168.10.63
```

We can choose:

```text
Router = 192.168.10.1
```

Then:

```text
Router Interface
192.168.10.1
     ↓
Default Gateway
     ↓
PCs / Phones / VMs
192.168.10.2 - 192.168.10.62
```

---

**🔥 Remember This**

```text
Default Gateway
→ The router's IP used to reach other networks.

Router Interface IP
→ An IP assigned to the router on that particular network.

Same subnet
→ The device and gateway must be in the same network.
```
