### 1. What Is an Internet Gateway (IGW)?

**IGW = Internet Gateway**

An Internet Gateway is an AWS component that allows communication between a VPC and the internet when the required network settings are configured.

#### 🧠 Simple Definition

> **Internet Gateway = A connection point between an AWS VPC and the internet.**

#### 🌍 Real-Life Example

Imagine your house has a gate leading to the main road.

- House = VPC
- Gate = Internet Gateway
- Main road = Internet

The gate provides a way to reach the outside world. But having a gate does not mean every person inside the house can automatically go outside.

AWS works similarly. An Internet Gateway provides the connection point, but routing and other network settings must also be correct.

#### Simple Diagram

```text
             INTERNET
                 |
               GATE
                IGW
                 |
                VPC
```

**Remember:** Attaching an IGW to a VPC does not automatically give every resource internet access.

1. Internet Gateway (IGW)

An Internet Gateway allows communication between an AWS VPC and the internet.

Simple meaning: VPC network-inu purathekku, internet-lekku pokaanulla gate.

### 2. What Is a Route Table?

A Route Table is a collection of rules that tells network traffic where to go.

#### 🧠 Simple Definition

> **Route Table = A map that helps network traffic find its destination.**

#### 🌍 Real-Life Example

Imagine you are travelling to a shopping mall. You check Google Maps to decide which road to take.

A Route Table works in a similar way. It checks the destination and helps choose the appropriate network path.

#### Example

```text
Destination          Target
--------------------------------
10.0.0.0/16           local
0.0.0.0/0             Internet Gateway
```

A route has two important parts:

- **Destination:** Where the traffic wants to go.
- **Target:** Where the traffic should be directed next.

In this example:

- `10.0.0.0/16 → local` means traffic destined for the VPC's own IP range uses the local route.
- `0.0.0.0/0 → Internet Gateway` means traffic without a more-specific matching route can use the IGW route.

**Remember:** A route table decides the path. It does not guarantee that the destination is reachable.

2. Route Table

A Route Table contains rules that decide where network traffic should go.

Simple meaning: Data evidekku pokanam ennu decide cheyyunna vazhikalude list.

### 3. What Is `0.0.0.0/0` Public Routing?

`0.0.0.0/0` is a CIDR notation representing all possible IPv4 destination addresses.

When used as a route destination, it is commonly called the **default route**.

#### 🧠 Simple Definition

> **Public routing = Using a route table to direct internet-bound traffic towards an Internet Gateway.**

#### 🌍 Real-Life Example

Imagine you have a map with these instructions:

- If your destination is inside your town, follow the local roads.
- If no more-specific road is available for your destination, follow the main road towards the highway.

The default route is like that main road. It provides a general path when a more-specific route does not match.

#### Example Route Table

```text
Destination          Target
--------------------------------
10.0.0.0/16           local
0.0.0.0/0             Internet Gateway
```

#### Example A: Traffic going inside the VPC

Destination:

```text
10.0.2.25
```

This IP address belongs to the VPC's `10.0.0.0/16` range.

The traffic uses:

```text
10.0.0.0/16 → local
```

#### Example B: Traffic going outside the VPC

Destination:

```text
8.8.8.8
```

This IP address is outside the VPC's `10.0.0.0/16` range.

If no more-specific route matches, the traffic uses:

```text
0.0.0.0/0 → Internet Gateway
```

#### Important Rule: Most Specific Route Wins

AWS selects the **most specific matching route**.

For example, `10.0.2.25` matches the VPC's local route. The local route is more specific than `0.0.0.0/0`, so AWS selects the local route.

#### 🧠 Memory Trick

- Traffic inside the VPC's IP range → Local route.
- Traffic without a more-specific matching route → Default route.
- Default route pointing to an IGW → Common public-routing configuration.

**Remember:** The default route provides a path towards the IGW. It does not guarantee that every resource can access the internet.

3. 0.0.0.0/0 — Default Route

0.0.0.0/0 matches all IPv4 destination addresses. It acts as a default route when no more-specific route matches.

Example: 0.0.0.0/0 → IGW

Simple meaning: Vere specific route match aakunnillenkil, traffic Internet Gateway vazhi ayakkuka.

### 4. How Does an Internet Gateway Work with a Route Table?

An Internet Gateway alone is not enough to provide a route to the internet. The route table associated with the subnet must contain the appropriate route.

#### 🌍 Real-Life Example

Imagine your house has a gate, and you have a map showing the road to the highway.

- The gate gives you a way out.
- The map tells you which road to take.
- Without the correct directions, having a gate alone does not tell you which route to follow.

In AWS, the IGW provides the connection point, while the Route Table directs traffic towards it.

#### Example Configuration

```text
VPC CIDR: 10.0.0.0/16

Route Table
---------------------------------
Destination          Target
10.0.0.0/16           local
0.0.0.0/0             igw-12345
```

Here, `igw-12345` is an example Internet Gateway ID, not a resource created in your AWS account.

#### How to Understand This

1. Traffic destined for the VPC's own IP range uses the local route.
2. Traffic with no more-specific matching route can use the default route.
3. The default route directs that traffic towards the IGW.

#### Simple Diagram

```text
                 INTERNET
                     |
              Internet Gateway
                     |
                Route Table
                     |
             0.0.0.0/0 → IGW
                     |
               Public Subnet
                     |
                 EC2 Instance
```

This diagram explains the routing concept. It does not mean the EC2 instance automatically has internet access.

For direct internet communication, the resource also needs appropriate IP addressing and network settings.

### 5. What Is a Public Subnet?

A public subnet is a subnet whose associated route table has a route to an Internet Gateway.

#### 🧠 Simple Definition

> **Public Subnet = A subnet whose associated Route Table has a route to an Internet Gateway.**

A common IPv4 configuration is:

```text
0.0.0.0/0 → Internet Gateway
```

#### 🌍 Real-Life Example

Imagine a building with a road leading directly to the main highway.

The building has access to that road because of how the road is connected. That does not mean every person or room inside the building is automatically accessible to the public.

Similarly, a subnet is public because of its routing configuration.

#### Example

```text
VPC
 |
 └── Public Subnet
       |
       └── Associated Route Table
               |
               └── 0.0.0.0/0 → IGW
```

The route table must be associated with the subnet. A route in an unrelated route table does not automatically make this subnet public.

**Remember:** A subnet is public because of its routing configuration, not simply because it contains an EC2 instance or because an IGW is attached to the VPC.

---

### 6. Public Subnet Does Not Mean Automatic Internet Access

A subnet can be public, but an EC2 instance inside it might still be unable to communicate directly with the internet.

For example, the EC2 instance might not have a public IPv4 address.

Other required network settings, including security rules, must also allow the intended communication.

#### 🧠 Simple Definition

> **A public subnet provides the route, but each resource still needs the correct settings for internet communication.**

#### 🌍 Real-Life Example

Imagine your house has a gate leading to the main road, but your car has no way to get onto that road.

The gate exists, but that alone does not mean your car can make the journey.

In AWS:

- The public subnet has the IGW route.
- The EC2 instance may not have a public IPv4 address.
- Therefore, the instance does not automatically have direct internet connectivity.

#### Example

```text
Public Subnet
     |
     ├── Route Table has an IGW route
     |
     └── EC2 Instance has no public IPv4 address
```

#### 🧠 Remember the Difference

- **Public subnet:** Determined by the associated route table's IGW route.
- **Internet accessibility:** Depends on routing, the resource's IP addressing, and other required network settings.

These are related, but they are not the same thing.

### 7. What Happens If the IGW Default Route Is Deleted?

Suppose a route table contains:

```text
10.0.0.0/16 → local
0.0.0.0/0   → Internet Gateway
```

Now imagine the default IGW route is deleted.

The route table becomes:

```text
10.0.0.0/16 → local
```

#### 🌍 Real-Life Example

Imagine your town has:

- Local roads connecting places inside the town.
- A main road leading out of town.

If the main road is closed, you can still travel between places inside the town, but that particular road is no longer available for leaving town.

#### What Changes in AWS?

- VPC-internal communication can continue using the local route.
- The route table no longer has that default route to the IGW.
- Traffic without another matching route has no route through this route table to the internet.

#### Important

Deleting the IGW default route does not automatically delete the local route.

**Memory trick:** Remove the internet route, and you remove that default path—not the VPC's local route.
