## 1. What Is an Internet Gateway (IGW)?

**IGW = Internet Gateway**

An Internet Gateway is an AWS component that allows communication between a VPC and the internet when the required network settings are configured.

### 🧠 Simple Definition

> **Internet Gateway = A connection point between an AWS VPC and the internet.**

Imagine your house has a gate leading to the outside world. The gate provides a way out, but it does not mean everyone inside the house can automatically go outside or that strangers can enter every room.

In AWS:

- **VPC** = Your virtual network.
- **Internet Gateway** = A connection point between the VPC and the internet.
- **Route Table** = A set of rules that decides where network traffic should go.

### Simple Diagram

```text
              INTERNET
                  |
                  |
          Internet Gateway
                (IGW)
                  |
                  |
                 VPC
```

**Remember:** Attaching an Internet Gateway to a VPC does not automatically give every resource internet access. The route table and other required network settings must also be correct.

---

## 2. What Is a Route Table?

A Route Table is a collection of rules that tells network traffic where to go.

### 🧠 Simple Definition

> **Route Table = A map that helps network traffic find its destination.**

Imagine you are travelling to a place. You check a map to decide which road to take.

AWS uses route tables in a similar way. When network traffic needs to go somewhere, the route table helps select the appropriate path.

### Example

```text
Destination          Target
--------------------------------
10.0.0.0/16           local
0.0.0.0/0             Internet Gateway
```

A route has two important parts:

- **Destination:** The IP address or IP range the traffic is trying to reach.
- **Target:** Where the traffic should be directed next.

In this example:

- `10.0.0.0/16 → local` means traffic destined for the VPC's own IP range uses the local route.
- `0.0.0.0/0 → Internet Gateway` means traffic without a more-specific matching route can use the Internet Gateway route.

**Remember:** A route table decides the path. It does not guarantee that the destination is reachable.

---

## 3. What Is `0.0.0.0/0` Public Routing?

`0.0.0.0/0` is a CIDR notation representing all possible IPv4 destination addresses.

When used as a route destination, it is commonly called the **default route**.

### 🧠 Simple Definition

> **Public routing = Using a route table to direct internet-bound traffic towards an Internet Gateway.**

### Example Route Table

```text
Destination          Target
--------------------------------
10.0.0.0/16           local
0.0.0.0/0             Internet Gateway
```

Let's understand what these routes do.

### Example A: Traffic going inside the VPC

Destination:

```text
10.0.2.25
```

This IP address belongs to the VPC's `10.0.0.0/16` range.

The traffic uses:

```text
10.0.0.0/16 → local
```

### Example B: Traffic going outside the VPC

Destination:

```text
8.8.8.8
```

This IP address is outside the VPC's `10.0.0.0/16` range.

If no more-specific route matches, the traffic uses:

```text
0.0.0.0/0 → Internet Gateway
```

### Important Rule: Most Specific Route Wins

AWS selects the **most specific matching route**.

For example, `10.0.2.25` matches the VPC's local route. The local route is more specific than `0.0.0.0/0`, so AWS selects the local route.

### 🧠 Memory Trick

- Traffic inside the VPC's IP range → Local route.
- Traffic without a more-specific matching route → Default route.
- Default route pointing to an IGW → A common configuration for public routing.

**Remember:** The default route provides a path towards the Internet Gateway. It does not guarantee that every resource can access the internet.

## 4. How Does an Internet Gateway Work with a Route Table?

An Internet Gateway alone is not enough to provide a route to the internet. The route table associated with the subnet must contain the appropriate route.

### Example Configuration

```text
VPC CIDR: 10.0.0.0/16

Route Table
---------------------------------
Destination          Target
10.0.0.0/16           local
0.0.0.0/0             igw-12345
```

Here, `igw-12345` is an example Internet Gateway ID, not a real resource created in your AWS account.

### How to Understand This

1. Traffic destined for the VPC's own IP range uses the local route.
2. Traffic with no more-specific matching route can use the default route.
3. The default route directs that traffic towards the Internet Gateway.

### Simple Diagram

```text
                 INTERNET
                     |
                     |
             Internet Gateway
                     |
                     |
              Route Table
                     |
            0.0.0.0/0 → IGW
                     |
                     |
               Public Subnet
                     |
                 EC2 Instance
```

This diagram explains the routing concept. It does not mean the EC2 instance automatically has internet access.

For direct internet communication, the resource also needs appropriate IP addressing and network settings.

## 5. What Is a Public Subnet?

A public subnet is a subnet whose associated route table has a route to an Internet Gateway.

### 🧠 Simple Definition

> **Public Subnet = A subnet whose associated route table has a route to an Internet Gateway.**

A common IPv4 configuration is:

```text
0.0.0.0/0 → Internet Gateway
```

### Example

```text
VPC
 |
 └── Public Subnet
       |
       └── Associated Route Table
               |
               └── 0.0.0.0/0 → IGW
```

The route table must be associated with the subnet. A route in a different, unassociated route table does not automatically make this subnet public.

### Remember

A subnet is public because of its routing configuration, not simply because it contains an EC2 instance or because an Internet Gateway is attached to the VPC.

---

## 6. Public Subnet Does Not Mean Automatic Internet Access

This is one of the most important concepts from today's lesson.

A subnet can be public, but an EC2 instance inside it might still be unable to communicate directly with the internet.

For example, the EC2 instance might not have a public IPv4 address.

Other required network settings, including security rules, must also allow the intended communication.

### Example

```text
Public Subnet
     |
     ├── Route Table has an IGW route
     |
     └── EC2 Instance has no public IPv4 address
```

The subnet is public because of its route table. However, the EC2 instance does not automatically gain direct internet connectivity.

### 🧠 Remember the Difference

- **Public subnet:** Determined by the associated route table's IGW route.
- **Internet accessibility:** Depends on routing, the resource's IP addressing, and other required network settings.

These concepts are related, but they are not the same thing.

## 7. What Happens If the IGW Default Route Is Deleted?

Suppose a route table contains:

```text
10.0.0.0/16 → local
0.0.0.0/0   → Internet Gateway
```

Now imagine the default IGW route is deleted.

The route table becomes:

```text
10.0.0.0/16 → local
```

### What Changes?

- VPC-internal communication can continue using the local route.
- The route table no longer has that default route to the Internet Gateway.
- Traffic without another matching route has no route through this route table to the internet.

### Important

Deleting the IGW default route does not automatically delete the local route.

**Memory trick:** Remove the internet route, and you remove that default path—not the VPC's local route.

## 8. Important Examples to Remember

### Example 1 — Internet-bound traffic

Route table:

```text
10.0.0.0/16 → local
0.0.0.0/0   → IGW
```

Destination:

```text
8.8.8.8
```

**Result:** The default IGW route is selected if no more-specific route matches.

### Example 2 — VPC-internal traffic

Destination:

```text
10.0.2.25
```

**Result:** The `10.0.0.0/16 → local` route is selected because it is more specific than the default route.

### Example 3 — Public subnet, no public IP

The associated route table has an IGW route, but the EC2 instance has no public IPv4 address.

**Result:** The subnet is public, but the instance does not automatically have direct internet connectivity.

### Example 4 — Default route removed

The local route remains, but the IGW default route is deleted.

**Result:** The local route can still handle VPC-internal traffic. The deleted default internet path is no longer available.

## 9. Key Terms

**Internet Gateway (IGW):** An AWS component that enables communication between a VPC and the internet when routing and other required settings are configured.

**Route Table:** A collection of rules that determines where network traffic should go.

**Route:** A rule that contains a destination and a target.

**Destination:** The IP address or IP range the traffic is trying to reach.

**Target:** Where the traffic is directed next.

**Public Routing:** Routing configuration that directs internet-bound traffic towards an Internet Gateway.

**Default Route:** A route used when no more-specific matching route is available.

**`0.0.0.0/0`:** A CIDR destination that matches all IPv4 addresses and is commonly used as the default route.

**Local Route:** A route that enables routing within the VPC's own network range.

**Public Subnet:** A subnet whose associated route table has a route to an Internet Gateway.

## 10. Day 24 — Final Revision

Remember these five rules:

1. An Internet Gateway provides a connection point between a VPC and the internet.
2. A Route Table decides where network traffic should go.
3. `0.0.0.0/0` is the default IPv4 route when no more-specific route matches.
4. A subnet is public when its associated route table has a route to an Internet Gateway.
5. A public subnet does not automatically make every resource inside it accessible from the internet.

### One-Line Summary

> **The Internet Gateway provides the gateway, the Route Table selects the path, and `0.0.0.0/0` is the default IPv4 route commonly used to direct traffic towards the internet.**
