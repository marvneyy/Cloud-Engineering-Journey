### 1. What Is an Internet Gateway (IGW)?

**IGW = Internet Gateway**

An Internet Gateway is an AWS networking component that allows communication between a VPC and the internet when the required network settings are configured.

### 🧠 Simple Definition

> **Internet Gateway = A gateway that connects a VPC to the internet.**

Imagine your house has a gate leading to the outside world. The gate provides a way out, but it does not mean every room in your house is automatically accessible from outside.

In AWS:

- VPC = Your virtual network
- Internet Gateway = The internet gateway connected to that VPC
- Route Table = The rules that decide where network traffic should go

### Simple Diagram

```text
                INTERNET
                    |
                    |
            Internet Gateway
                  (IGW)
                    |
                    |
                   VPC
```

**Remember:** Attaching an IGW to a VPC does not automatically give every resource internet access. The routing and other required settings must also be correct.

### 2. What Is a Route Table?

A route table is a collection of rules that tells network traffic where to go.

### 🧠 Simple Definition

> **Route Table = A map that tells network traffic where to go.**

Imagine you are travelling to a destination. You check a map to decide which road to take.

AWS uses route tables in a similar way. When traffic needs to go somewhere, the route table helps AWS select the appropriate path.

### Example

```text
Destination          Target
--------------------------------
10.0.0.0/16           local
0.0.0.0/0             Internet Gateway
```

For this example:

- `10.0.0.0/16 → local` means traffic destined for the VPC's own IP range uses the local route.
- `0.0.0.0/0 → Internet Gateway` means the default route sends traffic that has no more-specific matching route towards the Internet Gateway.

The route table helps choose the path. It does not guarantee that the destination is reachable.

---

### 3. What Does `0.0.0.0/0` Mean?

`0.0.0.0/0` is a CIDR notation representing all possible IPv4 destination addresses.

When used as a route destination, it is commonly called the **default route**.

### 🧠 Simple Definition

> **`0.0.0.0/0` = The default path for IPv4 traffic when no more-specific route matches.**

### Example

Suppose a route table contains:

```text
10.0.0.0/16  → local
0.0.0.0/0    → Internet Gateway
```

Consider two destinations.

**Example A: Destination is `10.0.2.25`**

This address belongs to the VPC's `10.0.0.0/16` range.

The local route is more specific, so traffic uses:

```text
10.0.0.0/16 → local
```

**Example B: Destination is `8.8.8.8`**

This address is outside the VPC's `10.0.0.0/16` range. Assuming no other matching route exists, traffic uses:

```text
0.0.0.0/0 → Internet Gateway
```

### Important Rule

AWS selects the **most specific matching route**.

A default route does not override a more-specific route just because it matches many addresses.

### 4. How Does an Internet Gateway Work with a Route Table?

An Internet Gateway alone is not enough to provide a route to the internet. The associated route table must contain the appropriate route.

### Example Configuration

```text
VPC CIDR: 10.0.0.0/16

Route Table
---------------------------------
Destination          Target
10.0.0.0/16           local
0.0.0.0/0             igw-12345
```

Here, `igw-12345` is an example Internet Gateway ID.

### How to Read This

1. Traffic destined for the VPC's own CIDR uses the local route.
2. Traffic with a destination outside that range can use the default route if no more-specific route matches.
3. The default route sends that traffic towards the Internet Gateway.

### Diagram

```text
                INTERNET
                    |
                    |
              Internet Gateway
                    |
                    |
              Route Table
                    |
          0.0.0.0/0 → IGW
                    |
                    |
              Public Subnet
                    |
                EC2 Instance
```

This diagram shows the routing concept. Actual internet connectivity also depends on the instance's IP addressing and other required network settings.

### 5. Important Examples to Remember

### Example 1 — Internet-bound traffic

Route table:

```text
10.0.0.0/16 → local
0.0.0.0/0   → IGW
```

Destination:

```text
8.8.8.8
```

Result: The default IGW route is selected if no more-specific route matches.

### Example 2 — VPC-internal traffic

Destination:

```text
10.0.2.25
```

Result: The `10.0.0.0/16 → local` route is selected because it is more specific than the default route.

### Example 3 — Public subnet, no public IP

The associated route table has an IGW route, but the EC2 instance has no public IPv4 address.

Result: The subnet is public, but the instance does not automatically have direct internet connectivity.

### Example 4 — Default route removed

The local route remains, but the IGW default route is deleted.

Result: The local route can still handle VPC-internal traffic; the deleted default internet path is no longer available.

## 9. Key Terms

**Internet Gateway (IGW):** An AWS networking component that enables communication between a VPC and the internet when routing and other required settings are configured.

**Route Table:** A collection of rules that determines where network traffic should go.

**Route:** A rule containing a destination and a target.

**Destination:** The IP range or network that the traffic is trying to reach.

**Target:** The next destination or network component to which the traffic is directed.

**Default Route:** A route used when no more-specific matching route is available.

**`0.0.0.0/0`:** A CIDR destination that matches all IPv4 addresses; commonly used as the default route.

**Local Route:** A route that enables routing within the VPC's own network range.

**Public Subnet:** A subnet whose associated route table has a route to an Internet Gateway.
