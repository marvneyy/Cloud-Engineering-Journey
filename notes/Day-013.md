🎯 **Day 13 Goal**

Build a multi-subnet network in **Cisco Packet Tracer** and make two different networks communicate through routers.

---

📚 **What I Learned**

✅ A switch interface is a port where a network cable connects.

✅ A router interface is a physical port used to connect the router to a network.

✅ How to select a router interface using the CLI.

✅ How to assign an IP address and subnet mask to a router interface.

✅ How to turn on a router interface using `no shutdown`.

✅ Different subnets need a router to communicate with each other.

✅ How to test communication between different networks using `ping`.

---

🛠️ **Hands-On Lab**

Created a **multi-subnet network** using Cisco Packet Tracer.

### Network Topology

```text
PC1
 │
Switch A
 │
Router 0
 │
Router 1
 │
Switch B
 │
PC2
```

### Router Configuration

Configured the router interfaces using CLI:

```text
enable
configure terminal
interface g0/0/0
ip address [IP] [MASK]
no shutdown
```

Configured the router-to-router connection and assigned IP addresses to the interfaces.

---

### 📡 Ping Test

Tested communication between the two different networks using:

```text
ping 192.168.2.10
```

Successful replies confirmed that the two networks could communicate through the routers.
