## 1. What Is a Subnet?

A **subnet (subnetwork)** is a smaller network inside a larger network.

**Manglish:** Oru valiya network-ne cheriya networks aayi divide cheyyunnathaanu subnetting.

Example:

- VPC: `10.0.0.0/16`
- Subnet 1: `10.0.0.0/24`
- Subnet 2: `10.0.1.0/24`

A VPC can contain multiple subnets.

## 2. What Is CIDR?

CIDR stands for **Classless Inter-Domain Routing**.

The `/number` after an IP address is called the CIDR prefix. It tells us how many bits belong to the network portion of the address.

Example: `10.0.0.0/24`

- IPv4 address size: 32 bits
- Network bits: 24
- Host bits: 32 − 24 = 8

### CIDR Quick Revision

| CIDR | Host bits | Total IP addresses | Normally usable host IPs |
|---|---:|---:|---:|
| `/24` | 8 | 256 | 254 |
| `/25` | 7 | 128 | 126 |
| `/26` | 6 | 64 | 62 |

**Formula:**

- Host bits = 32 − CIDR prefix
- Total addresses = 2^(host bits)
- Normally usable hosts = total addresses − 2 for standard IPv4 subnets

The network and broadcast addresses account for the two excluded addresses in these examples.

## 3. Our VPC Subnetting Example

Our VPC CIDR is:

`10.0.0.0/16`

For this exercise, we selected four `/24` subnets from that VPC range.

| Subnet | CIDR | Total IPs | Normally usable host IPs |
|---|---|---:|---:|
| Subnet 1 | `10.0.0.0/24` | 256 | 254 |
| Subnet 2 | `10.0.1.0/24` | 256 | 254 |
| Subnet 3 | `10.0.2.0/24` | 256 | 254 |
| Subnet 4 | `10.0.3.0/24` | 256 | 254 |

**Important:** A `/16` can contain many `/24` subnets. We are choosing four of them for this diagram, not splitting the entire `/16` into only four `/24` subnets.

## 4. What Is an Availability Zone (AZ)?

An Availability Zone is an isolated location within an AWS Region.

- **Region:** A geographic AWS location.
- **Availability Zone:** An isolated infrastructure location within a Region.
- **Subnet:** A network range associated with one Availability Zone.

For this exercise, our chosen Region is UAE (`me-central-1`).

We mapped the subnets like this:

- Availability Zone A: Subnets 1 and 2
- Availability Zone B: Subnets 3 and 4

Using multiple Availability Zones can help improve application availability when the architecture is designed to handle failures.

## 5. Public IP vs Private IP

A **Public IP** is an IP address that is globally routable on the public internet.

Example: `8.8.8.8`

A **Private IP** is used inside private networks.

Example: `10.0.0.1`

The `10.0.0.0/8` range is reserved for private IPv4 networks, so all four subnet ranges in our diagram are private IP ranges.

### Remember

**Private IP range does not automatically mean Private Subnet.**

## 6. Public Subnet vs Private Subnet

### Public Subnet

A subnet is considered public when its associated route table has a route to an Internet Gateway (IGW).

### Private Subnet

A private subnet does not have a direct route to an Internet Gateway.

A private subnet may still have other ways to reach external services, depending on its network configuration.

| Public Subnet | Private Subnet |
|---|---|
| Has a route to an Internet Gateway | No direct route to an Internet Gateway |
| Can host internet-facing resources when configured appropriately | Commonly used for internal resources |
| A public IP and suitable security rules may be needed for inbound internet access | Resources are not directly reachable from the public internet through an IGW |

**Important:** A Public IP and a Public Subnet are different things. A resource's reachability also depends on routing, IP assignment and security rules.

## 8. Quick Revision

- **VPC:** A logically isolated virtual network in AWS.
- **Subnet:** A smaller network range inside a VPC.
- **CIDR:** Notation that specifies the network prefix length.
- **Availability Zone:** An isolated infrastructure location within an AWS Region.
- **Public IP:** A globally routable internet IP address.
- **Private IP:** An IP address used within private networks.
- **Public Subnet:** Has a route to an Internet Gateway.
- **Private Subnet:** Has no direct route to an Internet Gateway.

### Important Formulas

`Host bits = 32 − CIDR prefix`

`Total IPv4 addresses = 2^(host bits)`

For a standard `/24` subnet:

`Host bits = 32 − 24 = 8`

`Total IPs = 2^8 = 256`

`Normally usable host IPs = 256 − 2 = 254`
