## Topics

• Network
• Client vs Server
• Server

• Communication

---

### 1. What is a Network?

Answer:
A network is a group of devices connected together to share data and resources.

Real-life Example:
Your phone, laptop, smart TV, and printer connected to the same Wi-Fi form a network.

---

### 2. What is a Server?

Answer:
A server is a computer that provides services or data to other computers (clients).

Real-life Example:

PC1
 │
PC2
 │
Switch
 │
Router
 │
Internet
 │
Server

---

### 3. What is a Firewall?

Answer:
A firewall protects the network by allowing safe traffic and blocking unwanted traffic.

---

### 4. What is a WAP?

Answer:
A WAP (Wireless Access Point) provides Wi-Fi connectivity to wireless devices.

---

### 5. What is Client vs Server?

Answer:

Client → Requests data

Server → Provides data

Example:
Phone → YouTube Server

---

### 6. How do they communicate?

Client → Switch → Router → Internet → Server

Server → Internet → Router → Switch → Client

---

### 7. What is an IP Address?

Answer:
An IP address is a unique address assigned to every device on a network.

Example:
192.168.1.10

---

Summary

✅ Network = Connected devices

✅ Client = Requests data

✅ Server = Provides data

✅ Firewall = Protects the network

✅ WAP = Provides Wi-Fi

✅ IP Address = Unique device address
