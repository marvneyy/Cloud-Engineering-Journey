 1. Network Address Reservation (Network ID)

The **Network ID** is the first address of a subnet.

It identifies the subnet itself.

Example

```
192.168.1.0/25

Network ID = 192.168.1.0
```

The Network ID is not normally assigned to a device.

---

2. Broadcast Address

* **Broadcast Address** is used to send a message to all devices in the same network.
* **Broadcast ID** is the last address of a subnet.

Example

```
192.168.1.0/25
```

Range

```
192.168.1.0 → 192.168.1.127
```

Therefore:

```
Network ID = 192.168.1.0
Broadcast  = 192.168.1.127
```

Address Breakdown

```
192.168.1.0    → Network ID ❌ Device
192.168.1.1    → Device ✅
192.168.1.2    → Device ✅
...
192.168.1.126  → Device ✅
192.168.1.127  → Broadcast ❌ Device
```

🧠 Easy Rule

```
Network ID = First Address
Host       = Middle Addresses
Broadcast  = Last Address
```

So, the **Broadcast Address itself is not a normal Host/Device address**. It is reserved for broadcasting to the subnet.

Example

```
Network   : 192.168.1.0
Host      : 192.168.1.1 - 192.168.1.126
Broadcast : 192.168.1.127
```

---

3. Bitwise AND

**Bitwise AND** is a mathematical operation used to find the **Network ID** from an IP address and subnet mask.

Rules

```
1 AND 1 = 1
1 AND 0 = 0
0 AND 1 = 0
0 AND 0 = 0
```

Example

```
IP   : 172.16.50.88
Mask : 255.255.255.192
```

Convert the important octet to binary:

```
88  = 01011000
192 = 11000000
```

Perform AND

```
  01011000
  11000000
  --------
  01000000
```

```
01000000 = 64
```

Therefore:

```
Network ID = 172.16.50.64
```

Basic Process

```
IP Address
    ↓
Convert to Binary
    ↓
AND with Subnet Mask
    ↓
Network ID
```

---

🧠 One-Line Memory Trick

> **Network ID = START | Host IPs = MIDDLE | Broadcast ID = END | Bitwise AND = finds the Network ID.**
